About AST → C++

Explore Clang text or JSON AST dumps and reconstruct approximate C++ expressions. Some original source details cannot be recovered from a dump.

Formatting runs locally in your browser using @wasm-fmt/clang-format, a WebAssembly build of Clang's formatter.

Share links compress the workspace locally with fflate and include the input text in the URL.

Notices: wasm-fmt (MIT) · fflate (MIT) · LLVM/Clang (Apache 2.0 with LLVM exceptions)
